# 轻待办 (LightTodo)

为小米手机量身打造的极简、纯本地待办应用。

## 设计目标

针对系统笔记 / Google Tasks / Todoist / 滴答清单的痛点：
1. **桌面小组件好看且能用**：2x2 圆角暗色卡，适配小米桌面，前面 [ ] 一点直接打勾
2. **纯本地**：不联网、不上传、不依赖账号
3. **同步小米日历**：单向只读拉取（小爱同学说"提醒我 xxx"会被记到日历，这里能看到）
4. **通知栏常驻快速添加**：下拉通知栏一秒记录
5. **暗色 UI 跟随系统**

## 功能一览

### 主界面
- 单列折叠列表，按标签分组
- 组内按创建时间排序
- 已完成单独折叠区域（默认折叠）
- 过期任务日期显示红色，未过期为浅灰
- 任务点 [ ] 后变删除线 → 移入"已完成"

### 任务模型
- 标题（可空，空时显示 note 首行 / "无标题"）
- 备注
- 日期（必填，存 yyyyMMdd 整数 + 当天 0 点时间戳，方便排序与过滤）
- 截止时间（可空，全天则为空）
- 提醒：
  - 有截止时刻 → 提前 N 小时（默认 2 小时）
  - 无截止时刻 → 当天默认时刻（默认 09:00）
- 标签（单标签，可空，输入即创建）
- 来自系统日历的任务为只读，仅可勾选完成

### 桌面小组件 2×2
- 暗色圆角，标题"今日安排"，右上 `>` 进 App
- 显示今日 + 已逾期未完成任务
- [ ] 可点击完成；点文字打开 App
- 不滚动（按用户要求）

### 通知栏常驻快速添加
- 设置中开启后，状态栏挂一条低优先级通知
- 点击 → 半透明对话框 → 一行输入 → 默认日期=今天 → 保存

### 小米日历同步
- 单向只读
- 默认只匹配账户名包含 "xiaomi / 小米 / mi.com" 的日历
- 自动过滤名字含"节日 / 假期 / 节假日 / Holidays"的日历，过滤 ACCOUNT_TYPE = LOCAL
- 设置中可手动指定账户名
- 时间窗口：今日起未来 60 天
- 已删除的日历事件会自动从待办中移除

### 数据导入导出
- 设置 → 导出 JSON / 导入 JSON
- 用于换机迁移和手动备份

## 技术栈

- Kotlin + Jetpack Compose
- Room (SQLite) + DataStore Preferences
- AlarmManager + 通知（精确闹钟，自动跳转申请权限）
- 桌面小组件：传统 RemoteViews + RemoteViewsService（不用 Glance，MIUI 兼容性更好）
- 日历：CalendarContract 直读
- minSdk 26（Android 8）/ targetSdk 34
- kotlinx.serialization 处理备份 JSON

## 构建

需要 Android Studio Hedgehog (2023.1.1) 或更新版本。

```bash
./gradlew :app:assembleDebug
```

APK 输出位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 首次使用流程

1. 安装并打开 App，按提示授予通知权限
2. Android 12+ 设备会跳转"精确闹钟"权限页，授予后才能准时提醒
3. 想用日历同步：进入"设置" → 打开"同步小米日历"，授予日历权限 → 点"立即同步一次"
4. 想用通知栏快速添加：设置中开启即可
5. 长按桌面空白处 → 添加小组件 → 选择"轻待办" 2×2 组件

## 已知限制

- 不内建语音输入（小爱同学未对第三方 App 开放 API）。语音录入依赖：
  - 系统输入法的麦克风按钮
  - 或在小爱训练计划里手动绑定 App 快捷指令
- 没有重复任务、子任务、优先级等高级字段（按需求精简）
- 2×2 小组件不滚动（按需求设计）
